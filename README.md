# Excel Unlocker Web App

A simple web application that allows users to register/login and remove password protection from Excel files (Workbook + Worksheet + VBA).

## Features

- User registration & login (email + password)
- Secure password hashing (bcrypt)
- Remove Excel Workbook protection
- Remove Excel Worksheet protection
- Optional VBA project unlock
- Clean and modern UI (Streamlit)
